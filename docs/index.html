FallenOWL Wallpaper Publisher

A planned Windows application for the FallenOWL creator to prepare and publish wallpaper Pins to their own Pinterest account.

The creator will select each image, choose a board, provide the text, and choose when to publish. The application is intended to use Pinterest OAuth and publish the selected Pins at the chosen times.

The Pinterest integration is planned and has not yet been approved. This is not a public service.
