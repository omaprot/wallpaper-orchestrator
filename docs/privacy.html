Privacy policy draft

This draft describes the intended data practices of the planned FallenOWL Wallpaper Publisher, a Windows application for the FallenOWL creator. The Pinterest integration has not yet been approved. This policy must be updated to reflect the application as actually built before it is used.

Information and use

The creator will select local images and enter Pin details, including a board, text and publication time. The application is intended to process this information locally and send selected images and Pin details to Pinterest for publication. It is intended to use Pinterest OAuth to obtain access to the creator's account; Pinterest credentials and tokens must be protected locally. The application is not intended to collect passwords.

The application is not intended to use advertising or analytics. Pinterest receives information submitted to its service and handles it under its own privacy policy.

Website hosting

These informational pages are intended to be hosted on GitHub Pages. GitHub may process technical information about visits under its privacy statement. The pages do not include third-party analytics or advertising scripts.

Access and deletion

The creator can revoke the application's Pinterest access through Pinterest account settings. The intended application will allow locally stored credentials and publishing data to be removed; revoking access or deleting local data does not automatically delete Pins already published on Pinterest. Published Pins can be managed through Pinterest.

Contact

Questions can be raised through the project's GitHub issues. Issues may be public: do not include passwords, tokens, or other sensitive information.
